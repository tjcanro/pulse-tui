Pulse · visual experiments

Actual terminal-renderer output at 24 fps. Every clip uses the same deterministic stereo test score, including a buildup and release. These silent recordings show generated spectra, not a captured song. Play matching clips from the start to compare their motion. No shader or browser graphics support is needed.

Selected default: Cinematic

A deliberate balance: camera motion stays slower than the pulses, with no beat shake. The more aggressive experiment is preserved as Surge.
