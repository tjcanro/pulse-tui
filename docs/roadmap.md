# Roadmap

## Stabilize the standalone project

- Check installation and native builds on another Mac and a Linux terminal.
- Expand sustained-music and quiet-track testing beyond synthetic input.
- Expand the README animation with recordings of mesh controls and ultrawide behavior.
- Decide licensing and release packaging.
- Split the prototype's Python application into modules when interfaces settle.

## Explore CAVA upstream interest

Prepare a focused proposal for an optional terminal wireframe mode, with a recording and measured performance. CAVA's contribution guidelines require opening an issue for discussion before a pull request.

If maintainers support the scope, consider porting remaining scene/projection logic to C and integrating CAVA's configuration and terminal lifecycle. Keep the standalone application working while that decision is explored.

This remains an independent project. No upstream issue or pull request has been opened.

References: [CAVA](https://github.com/karlstav/cava), [contribution guidelines](https://github.com/karlstav/cava/blob/master/CONTRIBUTING.md).
